# 南瓜头 · 书记员练习

在线使用：https://yolo-lele.github.io/nanguatou-typing/

根目录 `index.html` 为内嵌全部 CSS、JavaScript、文书和图片的独立网页；可维护源码在 `nanguatou-source.zip` 中。解压后，`node build.cjs standalone.html` 生成内嵌全部资源的独立网页。GitHub Pages 从 `main` 分支根目录自动构建并部署。

## 练习内容

- 50 篇文书：25 篇法院公开民事判决书原文，25 篇依据对应真实案件改写的民事起诉状。
- 覆盖民间借贷、买卖合同、劳务工资、建设工程、建筑设备租赁、金融借款等纠纷。
- 判决书取自永城市法院网、汝州市法院网，保留公开原文及原有匿名方式；仅规范网页排版空白，不按字符数删节。
- 起诉状在标题、正文及来源说明中标注“改写”，不是当事人实际提交的诉状原件；未公开的具状日期不作补写。
- 每篇均可展开“查看文书来源与说明”，查阅法院网页、案号及整理说明。历史判决中的法律引用、原网站笔误和不同当事人的主张均保留，不代表现行法律说明。
- 旧版 8 篇普法文章已全部移除。书架每页 10 篇，共 5 页，支持上一页、下一页和页码跳转；已移除分类筛选及旧普法说明条。

## 听写模式

在练习卡片中选择“听写模式”，点击“播放本句”。原文默认隐藏，支持上一句、下一句、重听、0.6–1.5 倍语速、连续朗读和 1/2/3/5 秒句间停顿。长句分段播放，不改变练习原文。默认读出标点、空格与换行，可自行关闭。

输入第一个字开始计时；暂停朗读时仍可输入，下方“暂停”同时暂停计时与声音。离开练习页、切换文章和结束练习都会停止当前朗读。继续朗读从当前句开头重听。成绩和 CSV 区分听写与对照打字，查看过原文的听写会注明。

使用浏览器 Web Speech API，无须配置 API 密钥。中文声音取决于系统和浏览器，可选择已安装声音或点击“重新检测”；在线声音需要联网。未检测到声音时提供提示，对照打字仍可使用。语音可能存在多音字、数字或符号读音差异，评分仍按原文逐位置比较。

## 使用与外观

保留自由练习、1/3/5 分钟限时挑战、自定义文章、暂停继续、专注模式、按键音和练习记录 CSV 导出。字号支持 12–32px，每次调整 1px，并在浏览器中记忆。

桌面采用左侧原文、右侧输入布局；窄屏自动上下排列。保留南瓜图标、粉色界面、一喵变猫多色 LABUBU、玩偶鼠标指针及连续猫爬架背景。

练习记录只保存在当前浏览器，最多 100 次，不上传 GitHub。沿用历史存储键，更新题库不会清空个人练习记录。角色及品牌权利属于各自权利人，AI 合成图片用于个人练习网页装饰。

## 源码与验证

`nanguatou-source.zip` 包含同版本的可维护源码、图片、25 份来源文本快照、案号与来源链接、SHA-256 校验值、文书生成脚本和 21 项自动检查。

解压后运行：

```sh
node preview.cjs
node --test tests/core.test.cjs tests/articles.test.cjs tests/dictation.test.cjs
node build.cjs standalone.html
```

文书数组可从保留的来源快照重新生成：`python build-articles.py`。生成脚本不联网，也不裁剪字数。
